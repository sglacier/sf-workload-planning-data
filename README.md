# Frozen SF workload-study data

36 required-field projections of public DataSF monthly snapshots, 2023–2025. Original: https://data.sf.gov/api/views/nuek-vuh3 . Dataset metadata specifies PDDL; https://data.sf.gov/terms-of-use also applies. No addresses, coordinates, ZIP or neighbourhood fields. Each file retains all source rows and selected field values. See snapshot_manifest.json for the original and derived hashes, byte sizes, field lists and row counts.

These are frozen research inputs, not current data, verified fleet occupancy or operational recommendations. The versioned release names this exact snapshot. Download paths should be pinned to its commit and checked against the manifest; a changed dataset requires a new release.
